# Hi, I'm Yuto Maruyama 👋

**AI agent engineer** at Illinois Institute of Technology. I build LLM agents that do real work: running a physical vending machine, underwriting real estate, scheduling meetings over LINE, and teaching dental patients.

**Agents & LLMs:** Anthropic Claude API (tool use, streaming, RAG), multi-agent orchestration, human-in-the-loop design, event sourcing
**Backend:** Python · FastAPI · SQLAlchemy 2.0 (async) · Pydantic v2 · TypeScript · Node · Hono · Postgres · Redis
**Frontend & Mobile:** React · Next.js · Vite · React Native / Expo · Swift
**ML:** PyTorch (JEPA / Transformers) · Jupyter · data pipelines
**Integrations:** LINE Messaging API + LIFF · Google Calendar · Supabase · Slack / Discord · Raspberry Pi GPIO
